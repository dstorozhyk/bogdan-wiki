# Канонічні процедури та принципи

## 1. Поповнення Freedom Brokers
- Використовуй лише Raiffeisen EUR → Wise EUR → Freedom EUR (0 fee)
- Уникай USD-конвертацій, карткових поповнень, прямого SWIFT/Paysera

## 2. Beauty public profile
- Структура: identity, services, slots, portfolio, відгуки, локація, Instagram-chat
- Не додавати: QR-код, дашборди, аналітику

## 3. Корпоративна стратегія Denys
- Пріоритет: системний вплив та ролі архітектора; не “стартапні понти”

## 4. Моніторинг вакансій
- Показувати лише вакансії з explicit booking
- Не показувати unconfirmed/not offered roles
